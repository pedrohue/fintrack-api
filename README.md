# FinTrack API

API REST para gerenciamento financeiro pessoal, desenvolvida com Node.js, Express e PostgreSQL.

O projeto tem como objetivo permitir que usuários controlem suas finanças, registrem receitas e despesas e acompanhem sua situação financeira.

## Tecnologias

- JavaScript
- Node.js
- Express
- PostgreSQL
- JWT
- Bcrypt
- Postman

## Funcionalidades

- Cadastro e autenticação de usuários
- Gerenciamento de receitas
- Gerenciamento de despesas
- Organização de categorias
- Controle de saldo
- Histórico de movimentações
- Relatórios financeiros mensais
- Filtros por período e categoria
